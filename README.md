分支：可以理解为代码的“平行宇宙”，让你在不影响主版本的情况下开发新功能。
合并：把“平行宇宙”里的修改拿回到主线上来。

cd：切换目录（如 cd folder 进入 folder）。

ls：列出当前目录下的文件和文件夹（Windows 下用 dir）。

mkdir：创建新文件夹（如 mkdir myProject）。

git add/commit/push：添加修改 → 提交到本地 → 推送到远程。

选择 MIT 协议，是因为它宽松且开源，允许他人自由使用和修改，只需保留版权声明，适合小型个人项目。
